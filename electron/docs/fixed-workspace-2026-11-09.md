# 固定分区工作台 — 2026-11-09

用户选择「固定分区」后落地正式 Electron 入口。本轮没有切换数据层、业务键、备份格式或应用标识，也没有改动 Android 目录。

## 展示与操作

- 左侧固定今日送货。今日单据数和金额始终按开单日期统计；今日／本月／全部只切换下面的列表，不改变今日汇总。
- 右上固定月度统计与近七日销售额，单位明确为元。右下固定当前单据、日期、客户、货品和金额。历史单据选择不再与今日信息混杂。
- 送货单导航和货车打开左侧查询区。沿用既有日期、自定义范围、搜索、合计和 CSV 导出；点选记录在固定详情区阅读，保留查询条件及列表位置。
- 统计在右侧原分区展开，沿用日期筛选、排行、月度账单和 Excel 导出。查看账单后返回原统计滚动位置。
- 新建/编辑、商品、客户和本机设置采用任务窗口。关闭任务返回原来的查询或详情，未保存修改仍需确认；保存后显示实际保存的单据。
- 打印与账单在专用阅读区展示，支持返回原位置。系统打印与 PDF 内容不包含工作台分区。
- 展开列表/详情/统计、编辑、打印和隐藏/最小化窗口时保持后台场景暂停；首页继续复用同一实例。

## 点击缺陷修复

1. 通用玻璃按钮反馈不再对 `.scene-marker` 施加位移变换。标签保留自己的 `translate(-50%, -100%)` 场景定位，鼠标按下和抬起落在同一目标。
2. 两个卷帘门改为普通装饰组，不属于单据拾取组。射线选择尊重可见场景遮挡，避免穿透装饰误点其后模型。
3. 货车只进入单据查询区，不直接打开任意选中的旧单据。
4. 固定分区承接今日送货和统计，场景中只保留商品、客户、开单和设置四类名称，移除重复分类名称。名称投影会避开两侧固定面板，提供可聚焦的按钮反馈。
5. 旧版 `sd_desktop_ui.focused` 数据保持兼容，但不再用它在启动时隐藏固定信息区。

## 唯一实现位置

- `renderer/src/shell.html`：固定区域结构。
- `renderer/desktop.js`：固定区域渲染、路由、视图复用、任务/阅读区和位置恢复。
- `renderer/desktop.css`：分区、展开状态及 1024×680 最小窗口适配。
- `renderer/warehouse-scene.js`：场景名称、投影、模型拾取与门口修正。
- `webapp/js/interactions.js`：场景标签不进入位移反馈。

生成文件继续只由构建脚本管理，没有引入新的依赖或第二套业务数据。

## 验证

新增 `npm run test:workspace` 共 12 组检查：

1. 固定区域与历史／今日数据口径。
2. 四类名称的真实鼠标按下、保持、抬起，以及按下期间的位置和命中目标。
3. 两个门口的原生模型射线点击不触发业务。
4. 货车模型打开固定查询区。
5. 选择记录原位更新；在展开统计时选择记录进入固定详情。
6. 查询筛选、详情和编辑关闭后的上下文保留。
7. 固定统计、月度账单和返回后的滚动位置。
8. 未保存确认、取消离开及真实保存结果。
9. 专用打印阅读区和返回原单据。
10. 1920×1080、1440×900、1024×680 区域边界、分区互不重叠、可见标签可点击。
11. 阅读、任务和隐藏窗口实际绘制帧数为 0。
12. 没有 HTTP 请求或渲染脚本异常。

原有 13 项数据/独立目录启动、9 项业务 UI、18 项桌面集成、2 组迁移、9 组场景生命周期和 5 组原生桥检查继续运行。共 68 项／组（不含性能采样、语法检查与安装包 10 项启动自检）。

实际生成并提取两份单据 PDF，均为一页，包含正确金额和 500ml 规格，没有工作台“送货现场”或 toast“已保存”。未向物理打印机出纸。

本轮性能采样为 Intel UHD Graphics / ANGLE D3D11：800ms 内首页 19 帧，展开业务区域和隐藏窗口均为 0 帧；5000 单据无变化刷新均值约 0.025ms，首次统计约 13.9ms。该结果是单机采样，不能与先前不同 GPU 的结果直接对比。

截图与专项结果：`.shots/fixed-workspace/`。完整测试均使用独立临时 profile，没有读取或覆盖日常业务记录。

## 安装包边界

检测到其他构建同时重建默认 `dist/win-unpacked`，本次固定分区验收采用独立输出目录，避免相互覆盖：

```powershell
npm run build:desktop-assets
node_modules/.bin/electron-builder.cmd --win --x64 --config.directories.output=dist/fixed-workspace
node scripts/verify-desktop-package.cjs dist/fixed-workspace
```

安装包位于 `dist/fixed-workspace/送货单统计 Setup 1.0.0.exe`。核验全部运行资源、安装包载荷及实际 EXE 启动，最终 SHA-256 和启动结果以 `.shots/fixed-workspace/package/package-verification.json` 为准。同期新增的内置商品图片及对应初始化改动予以保留，并包含在本次逐文件核验中。

保留前轮环境限制：仓库 `dist/win-unpacked` 下 EXE 直接运行可能提前退出；核验脚本同时使用安装包完整解压后的真实 EXE 和全新临时 profile 自检。未执行修改系统安装状态的安装/卸载流程；安装包没有商业签名。
