# 商品与客户资料自动识别导入

日期：2026-11-12。范围：Electron 项目的资料导入。此前的导出格式选择、JSON/ZIP 换机、原图备份、P1/P2 及开单重复商品合并功能保留。本次未更新 Android 项目、未生成新安装包。

## 使用方式

在“设置 → 表格导入导出”展开后，点击“商品资料”或“客户资料”行内的“导入”，直接选择 Excel 或 CSV，不需要选择导入格式，也不用将 Excel 另存为 CSV。

- 支持现代 `.xlsx` 和旧版 `.xls`，以及 CSV、制表符/分号分隔文本。
- 按文件内容识别，不仅检查文件扩展名。
- 自动跳过开头的说明/标题/空行，在前 50 行查找对应名称表头。
- 自动导入可见的匹配工作表，忽略无对应表头的说明页和隐藏工作表。一个文件作为一个批次保存。
- 当前应用导出的商品/客户 Excel 与 CSV 可以直接导回，包括 Excel 的“商品资料”“客户资料”标题行。

商品表需要“产品名称”列，也支持“商品名称”“品名”“名称”等表头。可选字段包括编号、条码、规格、单位、售价、成本、状态、备注、分类。客户表需要“客户名称”列，也支持“客户名”“姓名”“名称”等；可选电话、联系人、地址、备注。

## 数据处理

- 电话、条码、编号保持文本内容；自定义数字格式中的前导零也保留。
- 常规数字格式的长条码读取底层精确整数，不使用显示时缩短的科学计数法；超出安全整数范围的数字标识拒绝导入并指出单元格，要求核对原值并改为文本。
- 价格和成本使用底层数字，而非四舍五入后的显示文本。`0.125` 单元格即使显示为 `0.13`，也导入 `0.125`；零价格/零成本不当成空值。
- 商品状态支持在售/已下架等值；本应用导出文件中的独立状态列会恢复状态，原备注不混入状态。
- 商品按已有名称/规格或条码去重，客户按规范化名称去重，沿用原有“新增并跳过重复、不覆盖已有资料”的规则。
- 多个匹配工作表在同一事务中保存；无效价格、错误状态、错误单元格或写入失败时，不会留下前面工作表的部分导入。
- 不执行公式。公式有已保存的计算结果时读取结果；公式无结果或为错误值时中止并指出工作表及单元格。
- CSV 继续支持 UTF-8、带 BOM 的 UTF-16、GB18030、引号和多行备注。本应用 CSV 的防公式单引号在该文本导入流程中还原，不会执行对应内容。

若原 Excel 已把文本电话/条码转换成普通数字并删除前导零，文件中没有这些信息时无法猜回。图片仍通过完整 ZIP 备份迁移；资料表导入不把表格中的旧电脑图片路径当成图片文件。

## 性能与异常处理

- 主进程只选择文件和读取原字节；格式解析在独立 Worker 中进行。
- SheetJS CE 0.20.3 及其 Apache-2.0 许可证随应用本地打包。常规启动和非导入页面不加载该库，导入时不联网。
- 文件上限 32 MB，总记录数上限 100000，工作表列数上限 128；ZIP 解压大小另有限制。30 秒解析超时会结束 Worker。
- 成功、解析失败、超时都会终止对应 Worker。
- 两个导入按钮在进行中禁用，防止重复点击或相互交叉；取消不提示成功；出错后可重试。
- 本地数据已损坏时，先走原始数据抢救和有效备份恢复，禁止在不完整数据上继续导入。
