# P2 修复与验收

日期：2026-11-12。范围：当前 Electron 项目，原审查报告 R04–R12 共 9 项。P1 修复、含原图的 ZIP 换机备份继续保留。本次未更新 Android 项目，未重新打包安装包。

## 修复清单

| 编号 | 修复结果 | 主要实现 |
|---|---|---|
| R04 小数精度 | 数量和单价保留已存储 Number 的十进制有效位；如 `0.001 × 100.00 = 0.10`、`100 × 0.125 = 12.50`，预览、打印、PNG 和账单一致。数量合计按十进制累加，避免 `0.1 + 0.2` 出现长尾。最终金额继续使用原有两位规则，历史金额不重算。 | `util.js` 的 `formatDecimal` / `fmtNum` / `fmtPrice` / `sumQuantities`，以及相关展示与数量合计调用 |
| R05 账单备注 | 预览导出使用已应用的备注；统计页单客户及整月账单使用默认备注。Excel 合计下方生成合并的备注行，长备注分行，空行保留。账单预览也保留换行。 | `xlsx.js` 的 `sheet.note`，`views/bill.js`、`views/stats.js`、`styles.css` |
| R06 同名分享覆盖 | 使用排他创建写入文件；文件重名或清理文件名后发生碰撞时，自动生成 `(2)`、`(3)` 等后缀；并发分享也不会覆盖。 | `main.js` 的 `writeUniqueShareFile` |
| R07 CSV 公式风险 | 对可能被识别为公式的文本加前导单引号，覆盖 `= + - @`、前置空白及开头制表符/换行；数值列保持数值。仅处理导出文本，不修改数据库。 | `store.js` 的 `csvEscape` |
| R08 CSV 回车错行 | 引用判断包含 CR、LF、逗号、双引号及首尾空白；字段内双引号正确加倍，避免单独回车破坏记录边界。 | `store.js` 的 `csvEscape` |
| R09 XLSX 非法 XML | 将控制字符、孤立代理码元等编码为 SpreadsheetML 转义，保留有效 emoji；先保护原本就长得像 `_x000B_` 的文本，避免被误解释。 | `xlsx.js` 的 `escXml` |
| R10 导出旧关键词 | 输入时立即更新筛选状态，仅对列表渲染防抖；导出前同步当前输入并取消等待任务。清空搜索也取消旧任务。 | `views/orders.js` |
| R11 每秒快照淘汰历史 | 单独保存日期，跨重启检查磁盘上的当天快照；每天至多新增一份，保留 10 份历史，最新镜像另算；空启动不生成无意义历史。历史写入失败可见且可重试。 | `lib/data-store.js` |
| R12 快照混入业务键 | 排除聚合、历史及窗口状态文件；也过滤旧版已污染的聚合快照中的嵌套快照键。保留有效业务数据、界面偏好及原有历史文件，不再重新嵌套进新镜像。 | `lib/data-store.js` 的 `isSnapshotKey`、`listKeyFiles` 和加载流程 |

## 使用变化

- 正常两位单价仍显示为 `3.00`；三位单价如 `0.125` 不再被显示成 `0.13`。数量不再因两位显示规则变成零。
- 分享图片时，同名旧文件保留，新版本追加编号。普通“另存为”仍由保存对话框决定位置和覆盖行为。
- 同一天多次点击“立即备份”，会刷新最新镜像和图片，但不会重复新增历史快照。历史快照是当天首次可用状态，不是每次保存的版本历史。
- 旧版同日多份历史不会被主动合并；按现有历史保留数量正常滚动淘汰。被错误放进主数据目录的快照文件不会盲目删除，只是不再当业务键读取。
- CSV 的文本防护可能让普通文本读取器看到前导单引号；这是导出层的保护。需要完整迁移和保留原始字段时使用 ZIP 备份。
