# 今日送货关联侧滑预览

日期：2026-11-12。范围：Electron 工作台的单据摘要显示，不改业务数据结构和保存规则。原图 ZIP 备份、资料导入导出、P1/P2 与重复商品合并保持原有逻辑。未更新 Android 项目，未重新打包安装包。

## 交互

- 工作台不再常驻右下“当前单据”。启动或刷新页面时预览隐藏，原来的单据选中 ID 仍可用于快捷打印。
- 点击“今日送货”列表中的单据，紧贴列表右侧滑出预览卡片。高亮该单据行，在行与卡片之间显示连接线和指向缺口，明确数据来源。
- 点击另一行，原卡片切换到新单据并重新定位；再次点击当前行收起。
- 点击空白处、关闭按钮或 Esc 收起，关闭按钮/Esc 将焦点交回来源行。键盘方向右键可打开预览并聚焦“详细查看”。
- 切换今日/本月/全部范围时收起，避免详情与筛选后的列表失去关联。
- 滚动列表时预览跟随来源行；来源行滚出可见区域时自动收起。窗口尺寸变化时重算位置。
- 卡片顶部优先与来源行对齐，靠近底部时向上调整；长单据限制高度并在内容区域滚动，底部操作始终可见。
- 统计展开页点击同一左侧摘要列表，显示关联预览，保持统计路由和统计内容，不再直接跳全屏详情。

## 操作保留

预览仍提供详细查看、打印/导出、编辑和复制新增。打开任务/打印阅读页时隐藏预览，返回原位置可继续预览；主动回工作台时收起。完整单据详情仍有独立路由和完整阅读区域，不与摘要侧滑混淆。

列表高亮和详情读取同一 `selectedId`。订阅业务更新后重新绑定来源行；已选单据被删除时收起，不会无提示换成另一张单据。小数单价使用 P2 已修复的单价格式，不舍入成金额格式。

## 实现与性能

- 保留原 `context-panel` 及详情/动作实现，仅将摘要改为按需显示的固定定位卡片。
- 使用现有 DOM 高亮更新，单据点击不重绘整个摘要列表、不触发存储写入。
- 滚动和 resize 合并到下一帧定位；关闭时不持续轮询位置，销毁时取消帧和移除监听。
- 与场景动画暂停分离：关闭/暂停 3D 也不会把侧滑停在第一帧。减少动态效果设置下直接显示，不播放侧滑。
- 来源行不执行位移/缩放按压动画，避免按住按钮时来源坐标跳动。

## 验证
