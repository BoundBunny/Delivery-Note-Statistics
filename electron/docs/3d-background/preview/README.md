# P0 → P4 预览 · 使用说明

这是《[场景规格书](../scene-spec.md)》方向 2（三栏宽屏 + 微缩送货沙盘）的 **P0→P4 预览页**。
**P4 已把 3D 背景从 iframe 改成主页面直挂**（`3d/scene.js` + `js/bg3d.js`），预览页与工作台共用同一份场景代码。

## 打开方式

直接双击 `p0-blockout.html`，或拖进浏览器。页面现在只是薄壳：场景逻辑在同目录的 `scene.js`（依赖 `vendor/three.min.js`，r128 UMD，已本地化，无需联网）。

> 若浏览器对 `file://` 有限制，可在本目录起一个静态服务：
> `python -m http.server 8123`，再访问 `http://127.0.0.1:8123/p0-blockout.html`

### P1 精模升级（已完成）

- 车身/驾驶室/门店/货架背板换成 **圆角软体块**（Extrude + 倒角），车身补了侧窗、后视镜、尾门缝、轮毂、前灯、保险杠。
- 货架加四角立柱、隔板前挡边、实体分类牌与顶部灯条；托盘改成**板条结构**，纸箱加封箱胶带。
- 门店加**条纹雨棚、门窗框、玻璃、门口花箱、屋顶店招**；树木改为三层树冠，增加前景灌木。
- 月台加**卷帘门横条、门框、防撞胶块、装卸唇板、门口雨棚**；道路补虚线与停车线。
- 灯光加右侧补光；阴影统一为贴地假阴影。

### P2 数据与动效（已完成）

- **真实数据**：HUD 的「载入备份 JSON」直接解析 App 的 `Store.exportJSON()` 备份，计算今日单据/今日金额/本月金额/客户数/销量前三/最近单据并重绘场景；`?data=local` 可尝试读同源 `localStorage` 的 `sd_v1_orders`、`sd_v1_customers`；默认用演示数据。
- **动效**：新增在途小货车沿道路循环、叉车带货架→月台往返并举升、传送带 UV 滚动、货车按单据数显隐、展台高度随销量过渡、数据变化时箱堆/货架平滑重建。
- **数据适配层**：`loadBackup(obj)` / `computeFromData(orders, customers)` 已暴露在 `window.__preview`，真实接入时替换数据来源即可。

### P3 接入与性能（已完成）

- 新增 `webapp/js/bg3d.js`：用 **iframe 隔离**加载 `3d/p0-blockout.html?clean=1&dpr=1.5&maxfps=30`，3D 出错不影响主页面。
- 首页自动叠在现有工作台后面；设置页「基础资料 → 3D 工作台背景」可开关（`localStorage: sd_v1_bg3d`，默认开启）。
- **真实数据**：宿主通过 `postMessage` 把 `Store.listOrders()` / `Store.listCustomers()` 推给场景；保存单据后 12 秒内自动同步。
- **性能与兜底**：30fps 上限、DPR 1.5、窗口隐藏暂停；首帧 6 秒未就绪或 WebGL 失败自动回退 `3d/bg-static.png` 静态图。

### P4 原生化与自适应（已完成）

- **场景脚本化**：原内联脚本抽成 `scene.js`（`scripts/extract_scene.py` 抽取 + 打补丁），预览页变薄壳，工作台直接引同一份代码。
- **去掉 iframe**：`js/bg3d.js` 在主页面动态加载 `three.min.js` + `scene.js`，把画布交给场景；数据改成直接调 `DNS_SCENE.computeFromData()`，不再 postMessage。
- **窗口分级**：`<900` 不挂载；`900–1279` 精简（DPR 1.0/24fps）；`1280–1599` 标准（1.5/30fps）；`≥1600` 高（2.0/30fps）。
- **FPS 探针 + 自动降级**：连续低帧逐级降档（DPR 1.0→0.8→0.6，帧率 24→16→12），帧率在设置页那一行实时显示（页面上不再有常驻角标，避免压住内容）。
- **验收脚本**：`scripts/verify-bg3d.cjs`（20 项检查）、`scripts/verify-ui-readability.cjs`（可读性量化）、`scripts/diag-layout.cjs`（元素重叠体检）。

### P4.1 可读性优先（当前状态）

上一版 3D 整页铺底，场景会从卡片缝隙里透出来，界面读起来「叠在一起」，影响日常开单。
这一版按**老板优先**重做：

| 改动 | 说明 |
|---|---|
| 默认关闭 | 新装用户打开就是干净界面；需要演示再在设置里开 |
| 两档强度 | **柔化**（默认）＝纸色白纱 66% + 场景降档；**全开**＝撤掉白纱看完整场景 |
| 去掉常驻徽标 | 右下角帧率角标移除，帧率只在「设置 → 3D 工作台背景」那一行显示 |
| 场景卸载更干净 | `dispose()` 停主循环并释放 GPU，窗口变窄 / 关闭开关不残留占用 |

实测（1440×900，`scripts/verify-ui-readability.cjs`）：

| 指标 | 关闭 | 柔化 | 全开 |
|---|---|---|---|
| 首页内容区 3D 露出率 | 0 | **4.2%** | 13.8% |
| 设置页内容区 3D 露出率 | 0 | **0.8%** | 5.4% |
| 文字最差对比度 | 2.56 | 2.56 | 2.56（与背景无关，柔化不降分） |

> 「文字最差对比度 2.56」是设置页灰色说明文字（`--muted`，12px）在白卡片上的固有值，
> 与 3D 无关；开不开 3D 都一样。若要一并提升，可把说明文字色从 `--muted` 调深一档。

## 3D 导航怎么试

1. 点左栏 `商品管理`（或 6 个分类小胶囊）→ 场景会平移/拉近到对应货架，顶部出现「已定位」指引条。
2. 直接点场景里的彩色货架 → 左侧 `商品管理` 与对应分类同时高亮，并弹出「3D 场景 → 打开『商品管理 / 饮料』」路由提示。
3. 点月台/货车 → 单据；点打包台 → 开单；点门店 → 客户管理；点三级展台 → 统计。
4. **鼠标移到任意功能区域**：体块轻微上浮、地面焦点环呼吸，对应的聊天气泡放大成实色并显示「点击进入 →」；移到 6 个分类货架时会弹出大号分类气泡。
5. 点空地或指引条上的 `×` 回到工作台总览。

## 已知边界（P4 阶段）

- 场景已经直挂在主页面，不再有 iframe，但仍是「氛围层」：`pointer-events:none`，不抢占主界面点击；预览页里的拖拽/悬停交互只在预览页可用。
- 现有工作台侧栏（≥900px 时 228px 宽）为不透明导航条，3D 只在内容区的玻璃卡片下透出；导航条与页边留白不会显示场景。
- 移动端（<900px）不挂载 3D，直接走原页面。
- 场景按窗口宽度分级降档；帧率探针只统计场景自身绘制帧，`document.hidden`（窗口最小化/被遮挡）时暂停渲染与统计。
